# Scheduled FM and clipboard now playing — #99

Agent: Codex. Branch `codex/99-fm-countdown-clipboard`. Website only, existing Worker318 profile/music contract.

Scheduling no longer produces a success popup. The chat + menu FM badge displays the largest whole time unit (days/hours/minutes/seconds until live); the off-air FM card keeps Off air and adds a separate countdown pill. Both update each second using the FM server clock offset and switch to LIVE only on actual live state. At deadline while awaiting server state the label is Going live…. Clearing a schedule removes its countdown. Existing scheduling API/permissions are unchanged.

Signed-in foreground/open/resume checks use navigator.permissions to read clipboard automatically only when clipboard-read is already granted. Supported Apple Music, Spotify and SoundCloud track/share URLs show a small service-named prompt below the active top bar. A tap resolves metadata through the existing authenticated API and saves listening, preserving richer artist/explicit fields and updating profile state. No metadata call/profile write happens before the tap; unrelated clipboard text is ignored and not persisted/logged. Duplicate current/dismissed songs are suppressed, requests handle errors/retry and prevent double submits; auth identity is checked before save and after response.

Safari and other browsers often forbid automatic clipboard reads. They get an honest Use copied song for now playing prompt instead of a false detection claim. Its click invokes readText directly in the trusted click stack; if unavailable/denied, an inline paste field is offered. Normal paste events can also detect a supported link without intercepting the user's paste. No focus/keyboard change until explicitly using the restricted paste fallback. Prompt dismissal is supported. Native OS clipboard behavior cannot be proven by Linux Chromium mocks.

Validation: build/check/verify; focused browser cases for all three services, granted/prompt/denied permission, signed-out gating, zero background metadata/writes, metadata failure/retry, explicit persistence, duplicate/dismissal suppression, hostile clipboard URL rejection, small viewport placement. FM cases exercise scheduling UI with no toast, off-air pill,999 days/hours/minutes/seconds, ticking, clear and LIVE updates. Existing profile integration and FM upload/queue regressions pass. All API writes and clipboard contents are test mocks. Other UI test suites explicitly provide an empty permitted clipboard to avoid real environment clipboard access.
